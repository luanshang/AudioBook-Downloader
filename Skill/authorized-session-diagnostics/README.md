# 授权会话诊断 Skill

本 Skill 用于在用户明确授权、拥有设备和账号控制权的前提下，诊断第三方客户端的登录会话、认证失败和接口请求问题。它不用于自动提取、窃取、绕过访问控制或批量导出 Cookie、Token、密码、App 认证参数等凭证。

## 安全边界

- 只分析本人设备、本人账号和获得明确书面授权的测试环境。
- 抓包前关闭无关应用，避免采集其他账号或第三方数据。
- 不要分享或提交包含明文 `Cookie`、`Authorization`、`Token`、密码、设备标识、签名参数、二维码登录数据或临时下载地址的截图和导出文件。
- 分享日志前应遮盖敏感值，仅保留字段名、HTTP 状态码、接口路径和非敏感错误信息。
- 诊断完成后停止捕获、删除导出文件，并撤销测试凭证或退出登录。
- 不提供绕过验证码、付费墙、权限校验、DRM 或平台风控的方案。

## 推荐输出

诊断报告只应包含：时间、客户端版本、操作步骤、请求方法和路径、状态码、脱敏后的错误消息，以及是否可以稳定复现。不要包含可重放请求的完整 Header、Body 或认证字段。
